# 🍃 Agrocomercial Vida Sana — Firma Digital & Activos de Marca

Repositorio oficial con los activos de diseño, identidad visual y firmas de correo electrónico profesionales para **Agrocomercial Vida Sana** (Ricardo Hernández M., Director).

---

## 📁 Contenido del Repositorio

- **`index.html`**: Showcase y portal web interactivo con animaciones GSAP, selector de modo claro/oscuro y generador de copiado de firma.
- **`firma-email.html`**: Firma HTML independiente con botón de 1-click para copiar y pegar en Gmail, Outlook o Apple Mail (activos incrustados en base64).
- **`firma-email-servidor.html`**: Firma HTML optimizada para hosting externo o servidores web.
- **`ricardo_hernandez.vcf`**: Tarjeta de contacto vCard compatible con iOS y Android.
- **`VIDASANA FINAL.pdf`**: Manual de identidad visual y presentación de marca.
- **Logotipos & Gráficos**:

---

## 🚀 Uso Rápido

1. **Ver la firma en el navegador**: Abre `index.html` o `firma-email.html` en cualquier navegador web.
2. **Copiar la firma**:
   - Abre `firma-email.html` y pulsa el botón **"📋 Copiar Firma para Gmail / Outlook"**.
   - En tu cliente de correo (Gmail, Outlook, Mail de Apple), dirígete a Configuración > Firmas y pega el contenido (`Cmd + V` / `Ctrl + V`).
